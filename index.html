Cara Run BEN AGENT

Panduan dari nol lewat Termius. Tanpa domain. Tinggal salin, tempel, dan ikuti urutannya.

  • Sekitar 30 menit
  • Tanpa domain
  • Mulai dari mode simulasi

Siapkan dulu

  • VPS Ubuntu (alamat IP, username, dan password dari penyedia VPS).
  • Termius di HP atau komputer.
  • Akun Telegram.
  • Wallet Solana baru khusus untuk agent ini, isi saldo kecil saja.
  • API key Helius (gratis di helius.dev) dan API key OpenRouter (openrouter.ai).
  • File agentlp-clean.zip (file BEN AGENT yang kamu terima).
Cara pakai halaman ini

Tap tombol Salin di kotak perintah, lalu tempel di Termius (tekan lama layar, pilih Paste) dan tekan Enter. Kerjakan berurutan dari langkah 1.

1Buat bot Telegram

Bot ini hanya dipakai sebagai pintu untuk membuka Mini App.

  1. Buka @BotFather di Telegram, kirim /newbot, isi nama dan username (harus berakhiran bot).
  2. Salin token bot (bentuknya 123456789:AAH...). Simpan, jangan dibagikan.
  3. Buka @userinfobot, kirim pesan apa saja, lalu salin angka Id milikmu.

2Sambung ke VPS lewat Termius

  1. Buka Termius, masuk ke Hosts, tap tombol +, pilih New Host.
  2. Isi Address (IP VPS), Username (biasanya root), dan Password. Simpan.
  3. Tap host tersebut. Kalau muncul pertanyaan sidik jari (fingerprint), pilih Continue.

Kalau layar hitam dengan tanda $ atau # sudah muncul, kamu berhasil masuk.

3Pasang program pendukung

Tempel perintah ini satu per satu. Tunggu sampai selesai sebelum lanjut ke perintah berikutnya.

sudo apt update && sudo apt install -y unzip curl
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs
sudo npm i -g pm2
node -v

Hasil perintah terakhir harus diawali v22.

4Upload dan pasang BEN AGENT

  1. Di Termius buka tab SFTP, pilih host VPS-mu, lalu upload agentlp-clean.zip ke folder utama (home).
  2. Kembali ke terminal, lalu tempel perintah ini:
cd ~
unzip agentlp-clean.zip
cd agentlp
npm install
cp -n .env.example .env
Cek folder

Ketik ls index.js. Kalau muncul index.js, kamu sudah di folder yang benar. Kalau tidak, ketik cd agentlp lagi. Kalau nama file zip-mu berbeda, sesuaikan di baris unzip.

5Isi kunci dan pengaturan

File pertama: .env

nano .env

Ganti semua tulisan YOUR_... dengan data aslimu. Tulis langsung tanpa tanda kutip dan tanpa spasi.

BarisIsi dengan
WALLET_PRIVATE_KEYPrivate key wallet baru (Phantom atau Solflare, menu Export)
RPC_URLhttps://mainnet.helius-rpc.com/?api-key=KEY_HELIUS
HELIUS_API_KEYKey Helius
OPENROUTER_API_KEYKey OpenRouter (sk-or-...)
TELEGRAM_BOT_TOKENToken dari langkah 1
TELEGRAM_ALLOWED_USER_IDSAngka Id Telegram-mu
TELEGRAM_CHAT_IDAngka Id yang sama
PNL_RPC_URLSama seperti RPC_URL

Biarkan apa adanya: MINIAPP_URL (terisi otomatis di langkah 8), MINIAPP_PORT, MINIAPP_HOST, dan DRY_RUN=true.

Cara pakai nano

Geser dengan panah. Simpan: Ctrl+O lalu Enter. Keluar: Ctrl+X. Cari tulisan: Ctrl+W. Di HP, tombol Ctrl ada di baris tombol tambahan atas keyboard Termius.

File kedua: user-config.json

nano user-config.json

Cari dua baris ini dan ganti isinya. Tanda kutip di file ini harus tetap ada.

  • "llmApiKey" diisi key OpenRouter.
  • "pnlRpcUrl" diisi https://mainnet.helius-rpc.com/?api-key=KEY_HELIUS.
Jangan dilewati

Kalau llmApiKey masih YOUR_APIKEY, bagian AI akan gagal karena kuncinya salah.

6Tes jalan

npm start

Cari tulisan Mini App jalan di 127.0.0.1:8790 dan Mode: DRY RUN. Lalu buka sambungan Termius kedua (tab baru ke host yang sama) dan ketik:

curl http://127.0.0.1:8790/healthz

Kalau membalas ok, berarti jalan. Kembali ke tab pertama, tekan Ctrl+C untuk berhenti.

7Jalankan 24 jam (PM2)

cd ~/agentlp
npm run pm2:start
pm2 save
pm2 startup

pm2 startup mencetak satu baris panjang yang diawali sudo env PATH=.... Salin baris itu, tempel, tekan Enter, lalu jalankan:

pm2 save

Cek dengan pm2 status. Statusnya harus online.

8Buat link Mini App (tanpa domain)

Telegram hanya mau membuka Mini App lewat alamat https. Kita pakai terowongan gratis Cloudflare yang memberi link acak. Tidak perlu akun dan tidak perlu domain.

Pasang cloudflared

uname -m

Kalau hasilnya x86_64, pakai perintah ini:

curl -L https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb -o cf.deb
sudo dpkg -i cf.deb

Kalau hasilnya aarch64, ganti amd64 menjadi arm64 di perintah di atas.

Buat skrip pembuat link

Tempel satu blok ini sekaligus. Skrip ini membuat link baru, menaruhnya di .env, dan menyalakan ulang agent.

cat > ~/agentlp/ganti-link.sh <<'EOF'
#!/bin/bash
cd ~/agentlp || exit 1
PORT=$(grep -E '^MINIAPP_PORT=' .env | cut -d= -f2 | tr -d '[:space:]')
PORT=${PORT:-8787}
pkill -f "cloudflared tunnel" 2>/dev/null
sleep 1
nohup cloudflared tunnel --url http://127.0.0.1:$PORT > ~/tunnel.log 2>&1 &
echo "Membuat link, tunggu sebentar..."
LINK=""
for i in $(seq 1 30); do
  LINK=$(grep -o 'https://[a-z0-9-]*\.trycloudflare\.com' ~/tunnel.log | grep -v '^https://api\.' | head -1)
  [ -n "$LINK" ] && break
  sleep 2
done
[ -z "$LINK" ] && echo "Gagal membuat link. Coba jalankan lagi." && exit 1
[ -n "$(tail -c1 .env)" ] && echo >> .env
sed -i '/^MINIAPP_URL=/d' .env
echo "MINIAPP_URL=$LINK" >> .env
pm2 restart agentlp --update-env
echo "Link baru: $LINK"
EOF
chmod +x ~/agentlp/ganti-link.sh

Jalankan skrip

~/agentlp/ganti-link.sh

Setelah 10 sampai 30 detik, muncul tulisan Link baru: https://....trycloudflare.com. Agent otomatis memasang tombol Mini App ke bot Telegram-mu memakai link itu.

9Buka Mini App di Telegram

  1. Buka chat pribadi dengan botmu (bukan grup), kirim /start sekali.
  2. Tombol Kantor LP muncul di sebelah kiri kolom ketik. Tap untuk membuka Mini App.
  3. Kalau tombolnya belum muncul, tunggu semenit, tutup Telegram sepenuhnya, lalu buka lagi.

Di kanan atas Mini App ada badge DRY RUN (simulasi) atau LIVE (uang sungguhan).

Link berubah? Ini normal

Link gratis ini berganti setiap kali terowongan dibuat ulang, misalnya setelah VPS restart. Agent trading tetap jalan 24 jam, karena Mini App hanya untuk melihat. Untuk mendapat link baru, jalankan lagi:

~/agentlp/ganti-link.sh

Lalu tutup dan buka lagi Telegram, dan tap tombol Kantor LP.

Perintah sehari-hari

PerintahFungsi
pm2 statusLihat agent hidup atau mati
pm2 logs agentlpLihat catatan kerja agent (keluar: Ctrl+C)
cd ~/agentlp && npm run pm2:restartNyalakan ulang setelah ubah pengaturan
pm2 stop agentlpHentikan agent
node cli.js positionsLihat posisi yang terbuka
node cli.js balanceLihat saldo wallet
node cli.js performanceLihat performa

Jalankan perintah node cli.js ... dari dalam folder ~/agentlp. Jangan jalankan npm start saat PM2 sedang aktif, karena akan bentrok.

Pindah ke LIVE (uang sungguhan)

Biarkan DRY_RUN=true selama beberapa hari sampai keputusan agent di Mini App terlihat masuk akal. Kalau sudah yakin:

cd ~/agentlp
nano .env

Ubah DRY_RUN=true menjadi DRY_RUN=false, simpan, lalu:

npm run pm2:restart
Risiko

Trading bisa rugi, termasuk kehilangan seluruh saldo wallet. Pakai uang yang siap hilang. Ini bukan saran keuangan.

Kalau ada masalah

Tombol Kantor LP tidak muncul

Pastikan kamu di chat pribadi dengan bot, kirim /start, lalu tutup total dan buka lagi Telegram. Kalau masih belum, jalankan ~/agentlp/ganti-link.sh.

Mini App putih atau tidak bisa dimuat

Link kemungkinan sudah mati. Jalankan ~/agentlp/ganti-link.sh, lalu buka lagi dari Telegram.

Muncul tulisan Akses ditolak

Angka Id di TELEGRAM_ALLOWED_USER_IDS salah, atau token bot di .env bukan token bot yang kamu buka. Perbaiki, lalu npm run pm2:restart.

Muncul tulisan Buka lewat Telegram

Mini App tidak bisa dibuka dari browser biasa. Buka lewat tombol di bot.

Bagian AI error atau 401

Cek llmApiKey di user-config.json dan OPENROUTER_API_KEY di .env. Isinya harus key OpenRouter yang benar.

Ada tulisan EADDRINUSE di log

Ada dua proses berjalan sekaligus. Ketik pm2 list dan hentikan yang dobel.

Data posisi kosong

Bisa jadi memang belum ada posisi, atau RPC_URL bermasalah. Cek dengan pm2 logs agentlp.

npm install gagal

Cek versi dengan node -v. Harus v22. Kalau bukan, ulangi langkah 3.

Keamanan

  • Pakai wallet baru khusus agent, dengan saldo kecil.
  • Jangan kirim file .env, private key, atau token bot ke siapa pun, termasuk lewat screenshot.
  • Kalau token bot bocor, buka @BotFather, kirim /revoke, lalu isi token baru di .env.
  • Mini App hanya bisa dibuka oleh Id Telegram yang kamu daftarkan di TELEGRAM_ALLOWED_USER_IDS.
