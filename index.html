1. Persiapan

Yang kamu butuhkan:

  • VPS Ubuntu (1 vCPU, 1–2 GB RAM)
  • Termius (aplikasi SSH)
  • Akun Telegram
  • Wallet Solana baru khusus bot (saldo kecil)
  • RPC Helius (helius.dev)
  • API Key OpenRouter (openrouter.ai)
  • Tidak perlu domain (pakai tunnel gratis)
Tips: Pakai wallet baru yang hanya berisi SOL secukupnya. Jangan pakai wallet utama.

2. Buat Bot Telegram

  1. Buka Telegram → cari @BotFather.
  2. Kirim /newbot → isi nama & username (harus berakhiran bot).
  3. Salin token bot. Simpan rahasia.
  4. Cari @userinfobot → kirim pesan → salin angka Id kamu.

Token = TELEGRAM_BOT_TOKEN
Id kamu = TELEGRAM_ALLOWED_USER_IDS

3. Siapkan VPS di Termius

Sambungkan ke VPS lewat Termius, lalu jalankan perintah berikut satu per satu:

sudo apt update
sudo apt install -y unzip curl
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs
sudo npm install -g pm2
node -v

Pastikan keluar versi Node.js 22.x.

4. Upload & Install Project

  1. Di Termius buka tab SFTP.
  2. Upload file agentlp-complete.zip ke folder home.
  3. Kembali ke terminal, jalankan satu per satu:
cd ~
unzip agentlp-complete.zip
cd agentlp
npm install
cp .env.example .env
cp user-config.example.json user-config.json
Perhatian: Kalau setelah unzip muncul folder agentlp/agentlp, masuk ke folder yang berisi index.js.

5. Konfigurasi

Edit .env

nano .env

Isi minimal (ganti dengan data kamu):

WALLET_PRIVATE_KEY=base58_private_key_kamu
RPC_URL=https://mainnet.helius-rpc.com/?api-key=HELIUS_KEY
OPENROUTER_API_KEY=sk-or-...
HELIUS_API_KEY=helius_key_kamu
TELEGRAM_BOT_TOKEN=123456:ABC...
TELEGRAM_ALLOWED_USER_IDS=123456789
MINIAPP_URL=https://xxxxx.trycloudflare.com
DRY_RUN=true

Simpan: Ctrl + O → Enter → Ctrl + X.

Edit user-config.json (opsional)

nano user-config.json
Mulai selalu dengan DRY_RUN=true supaya tidak pakai uang asli.

6. Jalankan dengan PM2

pm2 start ecosystem.config.cjs
pm2 save
pm2 startup

Cek log:

pm2 logs agentlp --lines 50

Perintah berguna lainnya:

pm2 restart agentlp
pm2 stop agentlp
pm2 status

7. Aktifkan Mini App (Kantor LP)

Mini App butuh HTTPS. Kita pakai Cloudflare Quick Tunnel (gratis, tanpa domain). Link-nya berubah setiap restart, tapi tidak masalah.

Install cloudflared

curl -L https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64 -o cloudflared
chmod +x cloudflared
sudo mv cloudflared /usr/local/bin/

Jalankan tunnel (link sementara)

cloudflared tunnel --url http://127.0.0.1:8787

Akan muncul URL seperti https://xxxxx.trycloudflare.com. Salin URL itu.

Isi URL ke .env

nano .env

Ubah baris MINIAPP_URL jadi URL yang tadi kamu salin, contoh:

MINIAPP_URL=https://xxxxx.trycloudflare.com

Simpan lalu restart agent:

pm2 restart agentlp
Catatan: Setiap kali kamu restart tunnel (atau VPS reboot), URL akan berubah. Tinggal ulangi langkah jalankan tunnel → salin URL baru → update MINIAPP_URL → pm2 restart agentlp.

Set Menu Button di BotFather

  1. Buka @BotFather.
  2. Kirim /mybots → pilih bot kamu → Bot Settings → Menu Button → Configure Menu Button.
  3. Isi teks (misal Kantor LP) dan URL Mini App yang sama.

Sekarang buka bot kamu di Telegram → tekan tombol menu → Mini App akan muncul.

8. Mode Degen

Mode Degen membuat filter lebih longgar supaya agent lebih cepat masuk ke coin yang baru mulai rame.

  • Buka Mini App → tab Setelan.
  • Aktifkan toggle Mode Degen.
  • Atau edit user-config.json → set "mode": "degen".

Tetap ada stop-loss dan proteksi risiko.

9. Troubleshooting

Agent tidak jalan

Cek log:

pm2 logs agentlp

Pastikan .env benar dan RPC valid.

Mini App tidak terbuka

Pastikan tunnel HTTPS aktif, MINIAPP_URL benar, dan Menu Button sudah di-set.

Mau live trading

Ubah DRY_RUN=false di .env, lalu:

pm2 restart agentlp --update-env

Mulai dengan jumlah SOL kecil.
