Cara Run BEN AGENT

Panduan lewat Termius, dari VPS kosong sampai tombol Mini App muncul di Telegram. Tanpa domain. Link boleh berganti setiap restart.

Tanpa domainGratis dengan Cloudflare Quick TunnelSalin-tempel perintah
Mulai dari langkah 1

1Siapkan bahan

Kumpulkan semuanya dulu supaya nanti tinggal menempel.

  • VPS Ubuntu yang bisa dibuka di Termius
  • Akun Telegram
  • Wallet Solana baru dengan saldo kecil
  • RPC Helius (helius.dev, gratis)
  • API key OpenRouter (openrouter.ai)
  • File agentai.zip

Buat bot Telegram sebagai wadah Mini App

  1. Di Telegram buka @BotFather, kirim /newbot, isi nama dan username (harus berakhiran bot).
  2. Salin token yang diberikan (bentuk 123456789:AAH...). Rahasiakan.
  3. Buka @userinfobot, kirim pesan apa saja, lalu salin angka Id kamu.
Simpan di catatan

Token bot dan ID Telegram dipakai di langkah 5.

2Siapkan VPS

Sambungkan ke VPS lewat Termius, lalu jalankan satu per satu.

Terminal
sudo apt update && sudo apt install -y unzip curl
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs
sudo npm i -g pm2

Cek hasilnya: node -v harus menampilkan v22.x.

3Install cloudflared

Alat ini membuat alamat HTTPS publik gratis. Telegram hanya mau membuka Mini App lewat HTTPS.

Cek jenis VPS dulu:

Terminal
uname -m

Jika hasilnya x86_64:

x86_64 (amd64)
curl -L https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb -o cf.deb
sudo dpkg -i cf.deb

Jika hasilnya aarch64:

aarch64 (arm64)
curl -L https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-arm64.deb -o cf.deb
sudo dpkg -i cf.deb

4Upload dan install project

  1. Di Termius buka tab SFTP, lalu upload agentai.zip ke folder home.
  2. Kembali ke terminal dan jalankan:
Terminal
cd ~ && unzip agentai.zip
cd agentai/agentai
rm -rf node_modules
npm install
Pastikan foldernya benar

Folder yang benar adalah yang berisi file index.js. Folder node_modules dihapus karena bawaan zip dibuat di komputer lain.

5Isi file .env

Terminal
nano .env

Semua nilai di file itu masih placeholder. Ganti yang berikut:

BarisIsi dengan
WALLET_PRIVATE_KEYPrivate key wallet baru (saldo kecil saja)
RPC_URLhttps://mainnet.helius-rpc.com/?api-key=KEYMU
HELIUS_API_KEYKey Helius yang sama
LLM_API_KEYKey OpenRouter (sk-or-...)
TELEGRAM_BOT_TOKENToken dari BotFather
TELEGRAM_ALLOWED_USER_IDSID Telegram kamu (angka)

Biarkan apa adanya: MINIAPP_URL (diisi otomatis oleh script), MINIAPP_PORT=8787, MINIAPP_HOST=127.0.0.1, DRY_RUN=true.

Simpan dengan Ctrl+O, tekan Enter, lalu keluar dengan Ctrl+X.

Jaga kerahasiaan

Jangan bagikan isi .env ke siapa pun, termasuk lewat screenshot.

6Buat script satu perintah

Script ini membuat link baru, memasukkannya ke .env, lalu menjalankan agent. Tombol di Telegram ikut diperbarui otomatis.

Tempel semuanya sekaligus:

Terminal
cat > mulai.sh << 'EOF'
#!/bin/bash
cd "$(dirname "$0")"
pm2 delete tunnel 2>/dev/null
rm -f /tmp/tunnel.log
pm2 start cloudflared --name tunnel --interpreter none -o /tmp/tunnel.log -e /tmp/tunnel.log -- tunnel --no-autoupdate --url http://127.0.0.1:8787 >/dev/null
for i in $(seq 1 30); do
  URL=$(grep -o 'https://[a-z0-9-]*\.trycloudflare\.com' /tmp/tunnel.log | grep -v '^https://api\.' | head -1)
  [ -n "$URL" ] && break
  sleep 1
done
[ -z "$URL" ] && { echo "Link belum ketemu, coba lagi"; exit 1; }
sed -i "s|^MINIAPP_URL=.*|MINIAPP_URL=$URL|" .env
pm2 delete agentlp 2>/dev/null
pm2 start ecosystem.config.cjs
echo ""
echo "Link Mini App: $URL"
EOF
chmod +x mulai.sh

7Jalankan dan buka di Telegram

Terminal
./mulai.sh

Tunggu sekitar 10 detik sampai muncul Link Mini App: https://...trycloudflare.com. Lalu:

  1. Buka chat pribadi dengan botmu di Telegram dan kirim /start.
  2. Tap tombol Kantor LP di kiri kolom ketik, atau tombol Open Miniapp di pesan start.
  3. Jika tombol belum muncul, tutup total aplikasi Telegram lalu buka lagi.

Cek bahwa semuanya sehat

Terminal
pm2 status
pm2 logs agentlp --lines 50
curl http://127.0.0.1:8787/healthz
  • agentlp dan tunnel harus berstatus online.
  • Log harus memuat Mini App jalan di 127.0.0.1:8787.
  • healthz harus membalas ok.

8Setelah restart dan pindah ke LIVE

Setiap VPS restart

Terminal
cd ~/agentai/agentai && ./mulai.sh

Link baru dibuat dan tombol di Telegram otomatis ikut berubah.

Jangan pakai pm2 save atau pm2 startup

Keduanya menyimpan link lama yang sudah tidak berlaku.

Pindah ke uang sungguhan

Biarkan DRY_RUN=true beberapa hari sampai keputusan di Mini App masuk akal. Lalu jalankan:

Terminal
nano .env      # ubah DRY_RUN=true menjadi DRY_RUN=false
./mulai.sh

Kendali manual

Mini App hanya untuk melihat data. Aksi manual lewat Termius:

Terminal
node cli.js positions
node cli.js balance
node cli.js close --position ALAMAT_POSISI

Masalah umum

Link tidak muncul setelah ./mulai.sh

Lihat log tunnel, lalu jalankan ulang script.

pm2 logs tunnel --lines 30
./mulai.sh
Mini App putih atau error 502

Cek pm2 status. Jika agentlp error, baca penyebabnya dengan pm2 logs agentlp. Biasanya ada isi .env yang belum benar.

Muncul "Akses ditolak"

TELEGRAM_ALLOWED_USER_IDS salah, atau bot yang dibuka berbeda dengan token di .env. Samakan keduanya lalu jalankan ./mulai.sh.

Muncul EADDRINUSE di log

Ada proses ganda di port 8787. Bersihkan lalu mulai ulang.

pm2 delete all
./mulai.sh
Tombol Kantor LP tidak muncul

Pastikan kamu membuka chat pribadi (bukan grup), kirim /start, lalu tutup total dan buka lagi aplikasi Telegram.

Mini App terbuka dari browser tapi minta "Buka lewat Telegram"

Mini App hanya bisa dibuka lewat tombol di bot Telegram, bukan dari browser biasa.

Wallet khusus bot dengan saldo kecil, dan jangan pernah membagikan private key atau token bot.
