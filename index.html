Panduan Running AgentLP di Termius

Langkah demi langkah. Selesai satu perintah? Lanjut yang berikutnya. Udah? Gas terus.

Isi:
1. Install Node & PM2 · 2. Upload & Install Project · 3. Isi .env · 4. Tes Jalan · 5. Cloudflare Tunnel · 6. Update MINIAPP_URL · 7. Tombol Mini App · 8. Jalan 24 Jam (PM2) · Bonus & Troubleshooting
Yang harus siap dulu: VPS Ubuntu, Termius sudah connect, wallet Solana baru (private key base58 + saldo kecil), Helius RPC key, OpenRouter API key, bot Telegram dari @BotFather, dan domain di Cloudflare.

1 Update & Install Node + PM2

Copy command ini, paste di Termius, enter:

sudo apt update && sudo apt install -y unzip curl curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash - sudo apt install -y nodejs sudo npm i -g pm2 node -v
Harus keluar v22.x. Udah? Lanjut step 2.

2 Upload & Install Project

Di Termius buka tab SFTP → upload file agentlp.zip ke folder home (/root atau /home/username).

Balik ke terminal, copy ini:

cd ~ unzip agentlp.zip cd agentlp npm install cp .env.example .env cp user-config.example.json user-config.json
Kalau setelah unzip jadi folder agentlp/agentlp, masuk ke folder yang ada file index.js-nya. Udah install? Lanjut.

3 Isi File .env

nano .env

Ganti semua placeholder berikut:

Yang digantiIsi dengan
WALLET_PRIVATE_KEY=Private key base58 wallet baru
RPC_URL=https://mainnet.helius-rpc.com/?api-key=KEY_MU
HELIUS_API_KEY=Key Helius yang sama
OPENROUTER_API_KEY=sk-or-... dari openrouter.ai
TELEGRAM_BOT_TOKEN=Token dari @BotFather
TELEGRAM_ALLOWED_USER_IDS=ID Telegram kamu (dari @userinfobot)
MINIAPP_URL=Isi nanti (contoh: https://kantor.domainmu.com)
Biarkan yang lain: MINIAPP_PORT=8787, MINIAPP_HOST=127.0.0.1, DRY_RUN=true.
Simpan di nano: Ctrl+O → Enter → Ctrl+X.

4 Tes Jalan Dulu

npm run test:syntax npm start

Cari tulisan Mini App jalan di 127.0.0.1:8787.

Buka tab Termius baru, lalu:

curl http://127.0.0.1:8787/healthz
Harus balas ok. Balik ke tab pertama, tekan Ctrl+C buat stop. Udah? Lanjut.

5 Cloudflare Tunnel (biar Mini App bisa diakses)

Cek arsitektur dulu:

uname -m

Kalau x86_64 pakai amd64 (command bawah). Kalau aarch64 ganti jadi arm64.

curl -L https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb -o cf.deb sudo dpkg -i cf.deb cloudflared tunnel login
Muncul link → buka di browser → pilih domain kamu → Authorize.

Lanjut:

cloudflared tunnel create kantor-lp

Catat Tunnel ID yang muncul.

cloudflared tunnel route dns kantor-lp kantor.domainmu.com

Ganti kantor.domainmu.com dengan subdomain kamu.

Buat config:

sudo mkdir -p /etc/cloudflared sudo cp ~/.cloudflared/TUNNEL_ID.json /etc/cloudflared/ sudo nano /etc/cloudflared/config.yml

Isi file config (ganti TUNNEL_ID dan domainmu):

tunnel: TUNNEL_ID credentials-file: /etc/cloudflared/TUNNEL_ID.json ingress: - hostname: kantor.domainmu.com service: http://127.0.0.1:8787 - service: http_status:404

Simpan, lalu jalankan permanen:

sudo cloudflared service install sudo systemctl enable --now cloudflared sudo systemctl status cloudflared
Harus muncul active (running). Udah? Lanjut.

6 Update MINIAPP_URL di .env

nano .env

Isi / ganti jadi:

MINIAPP_URL=https://kantor.domainmu.com
Simpan (Ctrl+O → Enter → Ctrl+X). Udah? Lanjut.

7 Pasang Tombol Mini App di BotFather

Di Telegram, chat @BotFather:

  1. Kirim /setmenubutton
  2. Pilih bot kamu
  3. Kirim URL: https://kantor.domainmu.com
  4. Kirim judul: Kantor LP

Alternatif lewat terminal (ganti TOKEN_BOTMU):

curl -s "https://api.telegram.org/botTOKEN_BOTMU/setChatMenuButton" \ -H "Content-Type: application/json" \ -d '{"menu_button":{"type":"web_app","text":"Kantor LP","web_app":{"url":"https://kantor.domainmu.com"}}}'
Balasan {"ok":true} = sukses. Buka chat bot → kirim /start → tombol Kantor LP muncul di kiri kolom ketik. Udah? Lanjut.

8 Jalan 24 Jam Pakai PM2

cd ~/agentlp npm run pm2:start pm2 save pm2 startup
Penting: pm2 startup akan mencetak satu baris panjang yang dimulai dengan sudo env PATH=.... Copy baris itu dan jalankan, lalu ketik lagi:
pm2 save

Pantau log:

pm2 logs agentlp

Atau cek status:

pm2 status
Harus jalan, dan Mini App bisa dibuka dari tombol Telegram. Selesai basic setup!

Bonus: Ubah Setting, LIVE, & Troubleshooting

Ubah pengaturan / restart:

cd ~/agentlp nano .env npm run pm2:restart

Pindah ke LIVE (uang sungguhan): edit .env → ganti DRY_RUN=false → npm run pm2:restart.

Kendali manual lewat CLI:

cd ~/agentlp node cli.js positions node cli.js balance node cli.js close --position ALAMAT_POSISI node cli.js claim --position ALAMAT_POSISI

Masalah umum:

  • Tombol nggak muncul → ulang step 7 + /start + restart Telegram
  • Mini App putih / tidak bisa dimuat → cek sudo systemctl status cloudflared + curl domain/healthz
  • Port bentrok (EADDRINUSE) → pm2 list lalu stop yang duplikat
  • Data posisi kosong → cek RPC di .env + pm2 logs agentlp
